# C-Quest: Learn & Play

An interactive, console-based C programming game designed to help beginners learn core programming concepts and practise them through quizzes and coding challenges.

## Learning Lessons

- Data Types
- Operators
- if-else Statements
- Loops
- Arrays

## Game Modes

- **Classic Quiz** — test your understanding of C fundamentals.
- **Guess the Output** — predict what a C program will print.
- **Bug Hunter** — identify and correct errors in code.
- **Fill in the Blank** — complete missing parts of C code.

## Features

- Five difficulty levels in each game mode.
- Score tracking and progress summaries.
- Level progression and unlocking based on performance.
- A beginner-friendly, terminal-based learning experience.

## Built With

- C
- Standard C library
- GCC
- Code::Blocks (development environment)

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/aeloneboy210-hash/C-Quest-Learn-Play.git
cd C-Quest-Learn-Play
```

### 2. Compile the source code

Make sure GCC is installed, then run:

```bash
gcc c_learning_game.c -o c_quest
```

### 3. Run the game

- **Windows:** `c_quest.exe`
- **Linux/macOS:** `./c_quest`
